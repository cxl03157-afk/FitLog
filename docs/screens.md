# 画面設計

## 1. 画面一覧・遷移図

```
[未認証]
  ├── /login          ← ログイン画面
  └── /register       ← 新規登録画面

[認証済み]
  ├── /               ← タイムライン画面（ホーム）
  │    └── 投稿カード クリック → /workout-posts/:id
  ├── /workout-posts/new   ← トレーニング記録投稿画面
  ├── /workout-posts/:id   ← 投稿詳細画面
  ├── /users/:id           ← プロフィール画面
  │    ├── フォロワー数 クリック → /users/:id/followers
  │    └── フォロー中数 クリック → /users/:id/following
  │    └── デバイス管理 クリック → /settings/sessions
  ├── /users/:id/followers ← フォロワー一覧画面
  ├── /users/:id/following ← フォロー中一覧画面
  ├── /search              ← ユーザー検索画面
  ├── /stats               ← 統計・集計画面
  └── /goals               ← 目標設定画面
```

---

## 2. 各画面の仕様

### 2-1. ログイン画面（`/login`）

**用途:** 既存ユーザーがメールアドレスとパスワードでログインする

**表示要素:**
- アプリロゴ・タイトル（FitLog）
- メールアドレス入力フィールド
- パスワード入力フィールド
- 「ログイン」ボタン
- 「アカウントを作成」リンク → `/register`

**アクション:**
- ログイン成功 → タイムライン画面（`/`）へ遷移
- ログイン失敗 → エラーメッセージ表示（「メールアドレスまたはパスワードが正しくありません」）

---

### 2-2. 新規登録画面（`/register`）

**用途:** 新規ユーザーがアカウントを作成する

**表示要素:**
- ユーザー名入力フィールド（英数字・アンダースコア、3〜20 文字）
- 表示名入力フィールド（1〜50 文字）
- メールアドレス入力フィールド
- パスワード入力フィールド（8 文字以上）
- 「登録する」ボタン
- 「ログインはこちら」リンク → `/login`

**アクション:**
- 登録成功 → タイムライン画面（`/`）へ遷移
- バリデーションエラー → フィールド下部にエラーメッセージ表示

---

### 2-3. タイムライン画面（`/`）

**用途:** 全体投稿（またはフォロー中ユーザーの投稿）を時系列で閲覧する

**表示要素:**
- ナビゲーションバー（ロゴ、検索・統計・目標・PR記録リンク、新規投稿ボタン、プロフィールリンク、ログアウト）
- タイムライン切り替えタブ（「全体」「フォロー中」）
- 投稿カード一覧（無限スクロールまたはページネーション）
  - ユーザーアバター・表示名・ユーザー名
  - トレーニング日付・タイトル
  - 種目・セット数サマリー
  - 投稿画像（最大 4 枚、サムネイル表示）
  - ナイス！数・コメント数
  - ナイス！ボタン
- 右下：投稿作成 FAB（Floating Action Button）→ `/workout-posts/new`

**アクション:**
- 投稿カードのユーザーエリア（アバター・表示名）クリック → `/users/:id`（投稿者プロフィール）
- 投稿カードのコンテンツエリア（タイトル・種目）クリック → `/workout-posts/:id`
- ナイス！ボタンクリック → ナイス！追加・解除（アニメーション）

---

### 2-4. トレーニング記録投稿画面（`/workout-posts/new`）

**用途:** 新しいトレーニング記録を作成する

**表示要素:**
- タイトル入力（例: 「胸の日」）
- トレーニング日付選択（デフォルト: 今日）
- 種目追加セクション
  - 種目カテゴリ選択 → 種目選択ドロップダウン（exercises マスタ）
  - セット入力テーブル（セット番号・重量kg・回数・メモ）
  - 「セット追加」ボタン
  - 「種目追加」ボタン（複数種目追加可能）
- 全体メモ入力テキストエリア（500 文字）
- 画像アップロード（最大 4 枚。プレビュー表示）
- 「投稿する」ボタン / 「キャンセル」ボタン

**アクション:**
- 投稿成功 → タイムライン（`/`）へ遷移

---

### 2-5. 投稿詳細画面（`/workout-posts/:id`）

**用途:** 投稿の全内容・コメント・ナイスを確認する

**表示要素:**
- 投稿者情報（アバター・表示名・ユーザー名）
- トレーニング日付・タイトル
- 種目一覧と各セット記録（重量・回数・PRフラグ・メモ）
- 投稿画像（フル表示、スワイプ可能）
- 全体メモ
- ナイス！ボタン・ナイス数
- 自分の投稿の場合：「削除」ボタン
- コメント一覧（コメント者アバター・表示名・内容・投稿日時）
  - 自分のコメント：「削除」アイコン
- コメント入力フォーム（280 文字以内）・送信ボタン

---

### 2-6. プロフィール画面（`/users/:id`）

**用途:** ユーザーのプロフィール・投稿履歴を閲覧する

**表示要素:**
- アバター画像（大）
- 表示名・ユーザー名（`@username`）
- 自己紹介
- 投稿数・フォロー中数・フォロワー数
- 自分のプロフィールの場合：「プロフィールを編集」ボタン・「アバター変更」ボタン
- 他ユーザーの場合：「フォロー」/「フォロー中」ボタン
- 過去の投稿一覧（グリッドまたはリスト表示）

**アクション:**
- プロフィール編集ボタン → 編集モーダル（表示名・自己紹介）
- アバター変更 → ファイル選択 → アップロード

---

### 2-7. ユーザー検索画面（`/search`）

**用途:** ユーザー名でトレーニング仲間を検索する

**表示要素:**
- 検索入力フィールド（ユーザー名でインクリメンタル検索）
- 検索結果一覧（アバター・表示名・ユーザー名・フォローボタン）

**実装仕様:**
- 300ms デバウンス後に `GET /api/users/search` を呼ぶ
- trim 後 2文字未満の場合はリクエストを送らない（バックエンドは1文字以上を受け付ける）
- 2文字未満に戻した際は検索結果・エラー・ローディングをすべてクリアし進行中リクエストを AbortController でキャンセル
- 自分自身の結果にはフォローボタンを表示しない

---

### 2-8. フォロー一覧画面（`/users/:id/followers`・`/users/:id/following`）

**用途:** フォロワー・フォロー中のユーザー一覧を確認する

**表示要素:**
- タブ切り替え（フォロワー / フォロー中）— Link で相互遷移
- ユーザーカード一覧（アバター・表示名・ユーザー名・フォローボタン）
- 0件時メッセージ・存在しないユーザー（404）メッセージ・API エラーメッセージ

---

### 2-9. 統計・集計画面（`/stats`）

**用途:** 自分のトレーニング頻度と種目別の成長を可視化する

**表示要素:**
- 期間切り替えタブ（週間 / 月間）
- トレーニング頻度グラフ（棒グラフ: 日別トレーニング回数）
- 総ボリュームグラフ（重量 × 回数の合計推移）
- 種目別最大重量推移グラフ（折れ線グラフ: 種目選択ドロップダウン）
- 期間サマリー（トレーニング日数・総セット数・最も多い種目）

---

### 2-10. 目標設定画面（`/goals`）

**用途:** 種目ごとの目標を設定し、達成状況を管理する

**表示要素:**
- 「目標を追加」ボタン
- 目標一覧カード（種目名・目標重量・目標回数・期限・状態バッジ）
  - 状態バッジ: `IN_PROGRESS`（青）/ `ACHIEVED`（緑）/ `ABANDONED`（グレー）
- 目標追加モーダル
  - 種目選択（exercises マスタ）
  - 目標重量 (kg) 入力
  - 目標回数 入力
  - 期限 日付選択
- 達成・放棄ボタン（IN_PROGRESS の目標のみ表示）

---

### 2-11. ログイン中デバイス管理画面（`/settings/sessions`）

**用途:** 現在ログイン中の端末セッションを確認し、不要な端末をログアウトする

**表示要素:**
- セッション一覧（端末名、最終利用時刻、IP、現在の端末バッジ）
- 「この端末を除く全端末をログアウト」ボタン
- 各行の「この端末をログアウト」ボタン

**アクション:**
- 個別ログアウト成功 → 対象セッション行を削除
- 全端末ログアウト成功 → 現在端末以外を即時削除
- 自端末をログアウトした場合 → `/login` へ遷移

---

| 目標リンク | `/goals` |
