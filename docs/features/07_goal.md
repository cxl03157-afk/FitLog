# 機能定義書：目標設定機能

## 1. 業務フロー

### 1-0. フィルタタブ
```
目標設定画面（/goals）を表示
    │
タブ切り替えで一覧を絞り込む
    ├── すべて（デフォルト）
    ├── 進行中（IN_PROGRESS）
    ├── 達成（ACHIEVED）
    └── 放棄（ABANDONED）
    │
GET /api/goals?status=<tab> でサーバーサイドフィルタリング
    │
タブ切り替え時に旧一覧をクリアしてローディング表示
```

### 1-1. 目標設定フロー
```
「目標を追加」ボタンをクリック
    │
目標追加モーダルを表示
    ├── 種目選択（exercises マスタ）※必須
    ├── 目標重量 (kg) 入力 ※任意（0.01〜1000）
    ├── 目標回数 入力 ※任意（1〜10000、整数）
    └── 期限 日付選択（任意、JST 基準の当日以降）
    │
「保存」をクリック
    │
クライアントバリデーション（種目必須、重量・回数どちらか必須、期限チェック）
    │
POST /api/goals でDB に保存（status: IN_PROGRESS）
    │
モーダルを閉じ、現在のタブ条件で一覧を再取得
```

### 1-2. 目標達成フロー
```
目標一覧でIN_PROGRESSの目標の「達成」ボタンをクリック
    │
PUT /api/goals/:id を実行（status: ACHIEVED, achieved_at: 現在時刻）
    │
現在のタブ条件で一覧を再取得
```

### 1-3. 目標放棄フロー
```
目標一覧でIN_PROGRESSの目標の「放棄」ボタンをクリック
    │
インライン確認 UI を表示（「本当に放棄しますか？」「放棄する」「キャンセル」）
    │
「放棄する」をクリック
    │
PUT /api/goals/:id を実行（status: ABANDONED）
    │
現在のタブ条件で一覧を再取得
```

### 1-4. 目標削除フロー
```
目標カードの「削除」ボタンをクリック
    │
インライン確認 UI を表示（「削除しますか？」「削除する」「キャンセル」）
    │
「削除する」をクリック
    │
DELETE /api/goals/:id を実行
    │
現在のタブ条件で一覧を再取得
```

## 3. 機能要件

### 目標データ仕様

| フィールド | 制約 |
|---|---|
| 種目 | 必須（exercises マスタから選択） |
| 目標重量 | 任意、0.01 以上 1000 以下（小数2桁まで） |
| 目標回数 | 任意、1 以上 10000 以下（整数） |
| 期限 | 任意、JST 基準の当日以降の日付 |
| ステータス | IN_PROGRESS / ACHIEVED / ABANDONED |

**バリデーション:**
- 目標重量と目標回数は少なくとも一方が必須（両方 null → 400 BadRequestException）
- 期限の過去日チェックはバックエンドで JST 基準（`Asia/Tokyo`）で実施。フロントエンドでも同基準で事前チェックする
- API 処理中（`isCreating` / `processingGoalId` / `deletingGoalId`）はボタンを disabled にして二重送信を防ぐ

### ステータス遷移

```
IN_PROGRESS
    ├── → ACHIEVED（達成ボタンクリック）
    └── → ABANDONED（放棄ボタンクリック）

ACHIEVED・ABANDONED は変更不可（読み取り専用）
```

### 表示仕様

| ステータス | バッジ色 | アクション |
|---|---|---|
| IN_PROGRESS | 青（indigo） | 「達成」「放棄」ボタンを表示 |
| ACHIEVED | 緑 | ボタン非表示、achieved_at を表示 |
| ABANDONED | グレー | ボタン非表示 |

- 目標重量・目標回数が null の場合は非表示（「0 kg」「0 回」と表示しない）
- 達成・放棄・削除の確認は `window.confirm` を使わずインライン UI で実施

## 4. API 設計

| メソッド | エンドポイント | 説明 | 認証 |
|---|---|---|---|
| GET | `/api/goals` | 目標一覧取得（自分のみ） | 必要 |
| POST | `/api/goals` | 目標作成 | 必要 |
| PUT | `/api/goals/:id` | 目標更新（status/期限変更） | 必要 |
| DELETE | `/api/goals/:id` | 目標削除 | 必要 |

### クエリパラメータ（GET `/api/goals`）

| パラメータ | 型 | 説明 |
|---|---|---|
| status | string | フィルタ（IN_PROGRESS / ACHIEVED / ABANDONED）。省略で全件 |
