# 機能定義書：目標設定機能

## 1. 業務フロー

### 1-1. 目標設定フロー
```
目標設定画面（/goals）を表示
    │
「目標を追加」ボタンをクリック
    │
目標追加モーダルを表示
    ├── 種目選択（exercises マスタ）
    ├── 目標重量 (kg) 入力
    ├── 目標回数 入力
    └── 期限 日付選択（任意）
    │
「保存」をクリック
    │
POST /api/goals でDB に保存（status: IN_PROGRESS）
    │
目標一覧に追加表示
```

### 1-2. 目標達成フロー
```
目標一覧でIN_PROGRESSの目標の「達成」ボタンをクリック
    │
PUT /api/goals/:id を実行（status: ACHIEVED, achieved_at: 現在時刻）
    │
目標カードのバッジを「達成」（緑）に変更
```

### 1-3. 目標放棄フロー
```
目標一覧でIN_PROGRESSの目標の「放棄」ボタンをクリック
    │
確認ダイアログ（「この目標を放棄しますか？」）
    │
PUT /api/goals/:id を実行（status: ABANDONED）
    │
目標カードのバッジを「放棄」（グレー）に変更
```

| 項目 | 内容 |
|---|---|
| UC-ID | UC-21 |

| 事後条件 | goals レコードが作成される（status: IN_PROGRESS） |

---

### UC-22: 目標達成・放棄

| 項目 | 内容 |
|---|---|
| UC-ID | UC-22 |
| ユースケース名 | 目標達成・放棄 |
| アクター | 認証済みユーザー（自分の目標のみ） |
| 事前条件 | ログイン済み、自分の IN_PROGRESS の目標が存在 |
| 事後条件 | status が ACHIEVED または ABANDONED に変更される |

---

## 3. 機能要件

### 目標データ仕様

| フィールド | 制約 |
|---|---|
| 種目 | 必須（exercises マスタから選択） |
| 目標重量 | 任意、0.0 以上 |
| 目標回数 | 任意、1 以上 |
| 期限 | 任意、当日以降の日付 |
| ステータス | IN_PROGRESS / ACHIEVED / ABANDONED |

### ステータス遷移

```
IN_PROGRESS
    ├── → ACHIEVED（達成ボタンクリック）
    └── → ABANDONED（放棄ボタンクリック）

ACHIEVED・ABANDONED は変更不可（読み取り専用）
```

### 表示仕様

| ステータス | バッジ色 | アクション |
|---|---|---|
| IN_PROGRESS | 青 | 「達成」「放棄」ボタンを表示 |
| ACHIEVED | 緑 | ボタン非表示、achieved_at を表示 |
| ABANDONED | グレー | ボタン非表示 |

## 4. API 設計

| メソッド | エンドポイント | 説明 | 認証 |
|---|---|---|---|
| GET | `/api/goals` | 目標一覧取得（自分のみ） | 必要 |
| POST | `/api/goals` | 目標作成 | 必要 |
| PUT | `/api/goals/:id` | 目標更新（status/期限変更） | 必要 |
| DELETE | `/api/goals/:id` | 目標削除 | 必要 |

### クエリパラメータ（GET `/api/goals`）

| パラメータ | 型 | 説明 |
|---|---|---|
| status | string | フィルタ（IN_PROGRESS / ACHIEVED / ABANDONED）。省略で全件 |
